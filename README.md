## why i want to make smth like this
This app is made to allow ppl with less programming knowledge to get together and make cool games, kinda like scratch does or flash did.
## what i got done
- a nice looking design using raw css with a bit of bundling
- a nice looking page
- a few pixel art graphics to spice up the whole thing
- a loading wasm based engine
- a working visual scripting language
- an editor for the said language
## what i want to get done
- a working sharing system for the games

## How to use editor
This is a short introduction on how to use editor. After booting the editor up you will get an left sidebar with list of entities press "add entity" it will add an entity, now drag it to the scene. Now that entities copy is in the scene we can press the pen icon near the entities entry on the sidebar to get to the node editor, in there you can add new nodes using the button on the right to add new nodes titled "+ Add Node" and to edit the graph you can drag the nodes around, and connect the different nodes to create new behaviors.
