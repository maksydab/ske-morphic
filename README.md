
# Ske-morphic
This is repository of Ske-morphic, a visual scripting site kinda like scratch.

## What i want to achieve
- a visual scirpting language that's node based
- an easily embeddable engine for running those games made in this editor
- a socialmedia like place for sharing games made using this editor
## what i got done
- a nice looking design using raw css with a bit of bundling
- a nice looking page
- a few pixel art graphics to spice up the whole thing
- a loading wasm based engine (currently only can read images)
## what i want to get done
- a working sharing system for the games
- a working visual scripting language
- an editor for the said language
